# Inventory Expanded 26.3

Port no oficial de [Inventory Expanded](https://www.curseforge.com/minecraft/mc-mods/inventory-expanded) (0.2.1, de nandinmac123) para Minecraft 26.3 con Fabric.

[Descarga el mod](https://github.com/Hub1349dev/Inventory-Expanded-26.3/releases/latest) y ponlo en `mods` junto a [Fabric API](https://modrinth.com/mod/fabric-api). En multijugador hace falta en cliente y servidor.
